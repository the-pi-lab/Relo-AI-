- **Fix:** add `express-rate-limit`, add `helmet`, require `ENCRYPTION_KEY` when `NODE_ENV=production`.

### M3. Mock/demo data leaking to real users
- `src/pages/Dashboard.tsx:153,175` — fallback reel captions ("How to get 10,000 email leads", "Never pay $180/year") render on API failure.

### M4. Dual icon systems + third-party font risk

- BubbledotICG via OnlineWebFonts: no SRI, third-party SPOF, privacy exposure; no `font-display` control.

- **Fix:** self-host Bubbledot in `public/fonts/` (fixes C3 too), drop FA or drop lucide (pick one), add image fallbacks.
